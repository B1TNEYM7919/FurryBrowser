🐾 FurryBrowser

Ваша приватность — в надёжных лапах.

FurryBrowser — лёгкий настольный браузер на базе Python, PyQt6 и QtWebEngine с собственным интерфейсом, поддержкой тёмной и светлой тем, удобной системой вкладок и встроенными инструментами защиты приватности.

Браузер сочетает минималистичный дизайн, привычные функции современных браузеров и дополнительные возможности управления пользовательскими данными.

Без лишнего визуального шума — только необходимые инструменты для комфортной работы в интернете.

✨ ВОЗМОЖНОСТИ

🪟 Интерфейс и управление

• Многовкладочный интерфейс с перемещением, закреплением, дублированием и выгрузкой вкладок.
• Собственная рамка окна с кастомной панелью заголовка и кнопками управления.
• Поддержка тёмной и светлой тем.
• Умная адресная строка с автодополнением из истории, закладок и открытых вкладок.
• Полноэкранный режим с поддержкой F11.
• Поиск по странице с подсветкой совпадений и навигацией между ними.

🔐 Приватность и безопасность

• Приватные окна с отдельным временным профилем.
• Отсутствие постоянного сохранения истории, cookies и кэша в приватном режиме.
• Запрос разрешений при обращении сайтов к геолокации, камере, микрофону, уведомлениям и буферу обмена.
• Геолокация по IP через ipwho.is и ipapi.co.
• Встроенная система уведомлений сайтов.
• Выборочная очистка истории, cookies, кэша, LocalStorage, IndexedDB и Service Workers.

🌐 Навигация

• Закладки с панелью быстрого доступа и отдельным менеджером.
• История посещений с возможностью повторного открытия страниц.
• Менеджер загрузок с отображением скорости и оставшегося времени.
• Пауза и возобновление загрузок.
• Открытие загруженных файлов и папок.
• Поддержка Nex Search, Google, DuckDuckGo, Bing и Яндекс.
• Возможность добавления собственных поисковых систем.

💾 Дополнительные возможности

• Восстановление предыдущей сессии.
• Сохранение открытых окон и вкладок.
• Запоминание размера и положения окна.
• Индивидуальное масштабирование для каждого сайта.
• Программно отрисованные иконки без дополнительных графических библиотек.
• Splash Screen с логотипом и индикатором загрузки.
• Собственные диалоговые окна и элементы управления.

📋 СИСТЕМНЫЕ ТРЕБОВАНИЯ

• Python 3.9+
• PyQt6
• PyQt6-WebEngine

Установка зависимостей:

pip install PyQt6 PyQt6-WebEngine

🚀 ЗАПУСК

python main.py

📦 СБОРКА

Для создания исполняемого приложения используется PyInstaller.

Установка:

pip install pyinstaller

Сборка:

pyinstaller --noconfirm --windowed --name FurryBrowser main.py

📁 ХРАНЕНИЕ ДАННЫХ

Все пользовательские данные хранятся в ~/.furrybrowser/

settings.json — настройки браузера.
session.json — сохранённая сессия.
history.json — история посещений.
bookmarks.json — закладки.
window_state.json — положение и размер окна.
zoom_levels.json — масштабирование сайтов.
downloads.json — список загрузок.
profile/ — профиль Chromium.
cache/ — HTTP-кэш.

⌨️ ГОРЯЧИЕ КЛАВИШИ

Ctrl + T — новая вкладка.
Ctrl + N — новое окно.
Ctrl + Shift + N — приватное окно.
Ctrl + D — добавить или удалить закладку.
Ctrl + Shift + O — менеджер закладок.
Ctrl + Shift + B — панель закладок.
Ctrl + H — история посещений.
Ctrl + J — менеджер загрузок.
Ctrl + , — настройки.
Ctrl + Shift + Del — очистка данных.
Ctrl + F — поиск по странице.
F11 — полноэкранный режим.
Esc — выход из полноэкранного режима.

🖼️ РЕСУРСЫ

Для полноценного оформления рекомендуется использовать папку assets/.

icon.png — иконка приложения.
about_art.png — изображение для заставки и окна «О программе».
art.png, art2.png, art4.png, art6.png — иллюстрации для диалоговых окон.

Если необходимые файлы отсутствуют, используются встроенные иконки и текстовые заглушки.

⚠️ ИЗВЕСТНЫЕ ОСОБЕННОСТИ

• Разрешения сайтов не сохраняются. Каждый запрос требует отдельного подтверждения.
• Полная очистка LocalStorage, IndexedDB и Service Workers может потребовать перезапуска браузера.
• В Wayland позиция окна может не восстанавливаться из-за ограничений протокола.
• Запуск от root в Linux автоматически добавляет флаг Chromium --no-sandbox. Запуск от имени суперпользователя не рекомендуется.
• Воспроизведение мультимедиа зависит от установленных системных кодеков и компонентов GStreamer.

Важно: FurryBrowser предоставляет инструменты управления приватностью, но не гарантирует полной анонимности или абсолютной защиты от отслеживания.
